# Передача проекта Айсане и Айше

Ветка собранного сервиса — backend. Проверять нужно точный SHA коммита,
переданный вместе со сборкой: `git rev-parse HEAD` должен совпадать с ним.

## Состав

- AI 2026.10.18.3: 52883e67b87671ff8faa4d7be6d003812de04fca.
- Rule Engine: dcc124cd50f764ee9754509a31afef7abda03536.
- Backend вызывает финальный app.rules.decision.build_job_result.
- cash_left_unattended получает дополнительные условия через публичный
  engine.model.check_service_context(frames, deadline). Старый ContextChecker
  и прямое обращение backend к приватному _generate удалены.
- cashier_leaves_during_service получает condition_checks в AI. Backend
  сохраняет эти условия и передаёт правилам без повторного вызова модели.
- Ошибки, partial и timeout возвращаются как failed. Диагностика показывает
  время этапов и оконное покрытие без содержимого видео и ответов модели.

## Финальная проверка

GPU-хост — ноутбук Айсаны с RTX 4050. По сообщению команды, прежние замеры на нём
укладывались в лимит; эту конкретную сборку ещё нужно проверить через интерфейс.
Результаты и таймауты RTX 3050 не переносить на RTX 4050.

Остановить старый worker, переключиться на согласованный коммит backend,
активировать рабочее AI-окружение, проверить локальные MODEL_PATH и API_KEY.
При необходимости добавить только web-зависимости:

```powershell
python -m pip install -r requirements-web.txt -c constraints-ai.txt
python -m pip check
python start_backend.py --mode real
```

Не устанавливать весь backend requirements поверх готового AI-окружения.
Проверенный NumPy 1.26.4 и CUDA PyTorch сохраняются. Ожидаемая строка startup:
Inference loaded: 2026.10.18.3. Интерфейс: http://127.0.0.1:8000/.

Для протокола приёмки записать SHA сборки, GPU, версию inference, длительность
видео, время задания и финальный статус/вердикт. Проверить положительный и
отрицательный размеченные примеры; искусственные фигуры не измеряют точность.

Профиль: 8 секунд на окно, overlap 2 секунды, 4 кадра, 448 px, бюджет 300 секунд,
refine=False, check_relevance=False. Лимит кооперативный: текущая операция CUDA
может завершиться позже. Изменения качества/скорости согласовывать с AI-командой.
