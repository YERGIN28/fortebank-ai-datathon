# Передача финальной сборки DataSAURs

Актуальная собранная версия находится в ветке **backend**. Корень репозитория
на GitHub по умолчанию может показывать другую ветку. Для проверки используйте:
https://github.com/YERGIN28/fortebank-ai-datathon/tree/backend

## Состав

- Inference `2026.10.18.10`, Qwen3-VL-4B-Instruct NF4.
- Правила `possible-signs-2026.10.18.1`, режим `possible_signs`.
- FastAPI, последовательный GPU-worker, веб-интерфейс, JSON и JPEG-доказательства.
- Профиль: окно 8 секунд, перекрытие 2 секунды, 4 кадра, до 640 px.
- `VERIFY_POSITIVE_CONDITIONS=false`; бюджет задания 300 секунд.

Не запускайте второй GPU-worker одновременно. Для нового компьютера следуйте README.

## Доступ для жюри

Публичные адрес и API-ключ передаются отдельно в форме сдачи, не в исходниках.
Временный туннель ведёт к ноутбуку команды: нужны питание от сети, отсутствие сна
и интернет. Перезапуск туннеля может изменить адрес. Перезапуск worker сохраняет
адрес туннеля, но удаляет результаты заданий из памяти.

Предыдущие документы AI4/AI7 отражают историю разработки. Для финальной сборки
приоритет имеют этот файл, корневой README и версия из `/health`.
