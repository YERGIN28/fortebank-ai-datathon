# Правила AI4.1 после проверки пакета Айши

Это исправленный source-only пакет на базе `rules-ai4.zip`, SHA256
`2584559c1707906b1042b860926ff1994a2b5d5cdb6c7dd2ee0c08c64d331342`.
Он предназначен для объединения владельцами правил и backend. Коммит не создан,
ветки не переключались, файлы участников в рабочем репозитории не заменялись.

## Изменение решения

Для трёх условных кассовых правил добавлен явный `temporal_policy`:

* `cashier_leaves_during_service`: обслуживание подтверждено на последнем
  доказательстве ухода, а не только до него.
* `cash_counting_without_customer`: наличные, пересчёт, видимость клиентской
  зоны и отсутствие клиента имеют общий доказанный момент; прямой приём
  подтверждён не позже него.
* `previous_cash_outside_storage`: наличные, отслеживание, текущий приём и
  нахождение предыдущих денег вне хранения имеют общий доказанный момент;
  предыдущий приём завершён не позже него. Сам непрерывный трекер не добавлен.

Сравниваются реальные точки доказательств. Промежуток между первым и последним
кадром не превращается в непрерывный интервал. Допуск `0.000001` секунды нужен
только для округления PTS; это НЕ допуск evaluator ±2 секунды.

Если временная связь не доказана, кандидат остаётся unresolved, без ложного
положительного или отрицательного вердикта. Другое подтверждённое событие
в том же видео сохраняется. Для подтверждаемого правила без корректной
временной политики финальное решение не выдаётся.

Таймкод события выбирается из совместно подтверждённых точек. Дополнительные
кадры контекста сохраняются, максимум три JPEG в публичном результате.
Интерфейс `build_job_result(job_id, inference_result, extract_frame)` прежний.

## Проверки

```powershell
python -B -m evaluation.check_rules --with-inference
python -B -m pytest -q
```

При точном AI 2026.10.18.4: первая команда — 194 теста, 406 подтестов,
0 skipped. В изолированной сборке backend 2da88c1 + AI4 + эти правила и
уточнённые backend fixtures: 234 passed, 406 subtests passed.
Предупреждение Starlette о будущей замене httpx не является ошибкой теста.

Добавлены 14 новых тестов временной связи. В двух старых положительных
fixtures правил и в двух fixtures backend согласованы доказательства на
моменте действия. Отдельные отрицательные тесты сохраняют противоречивые
времена и требуют unresolved. Это не скрытие старой ошибки: контрпример
явно включён в `evaluation/test_temporal.py`.

Для backend приложен отдельный patch `integration/backend_test_fixtures.patch`.
Он меняет только искусственные данные тестов, не production-код backend.
Если файл backend-тестов уже изменился, перенести эти два изменения вручную,
не заменять весь файл старой копией.

## Что не включено автоматически

Десять записей `AI4_REVIEW_RULES` остаются review_only. Их нормативные основания
и дополнительные scope/exception факты нельзя получить изменением флага.
В `RULES_CAPABILITIES.json` перечислены недостающие поля для каждой записи.

У `previous_cash_outside_storage` есть условный код решения, но в AI4
`previous_cash_continuously_tracked` принудительно unclear. Непрерывного
трекера нет. `inference_supported=False` в исходном каталоге сохранён.

Эта доработка не добавляет наблюдений, которых модель не видела, и не читает
реальные метки/описания. Применимость нормативов заново не пересматривалась.
Реальная точность и лимит 300 секунд здесь не измерялись.
