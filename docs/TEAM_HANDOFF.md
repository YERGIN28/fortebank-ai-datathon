# Быстрое подключение трёх правил

В общей ветке `codex/integrated-pipeline` соединён полный путь:
MOV → основной Qwen → дополнительный просмотр → условия трёх правил → JPEG → JSON.

Три поддерживаемых типа:

- cashier_leaves_during_service — п. 22 № 231;
- cash_counting_without_customer — п. 20, абзац 1;
- previous_cash_outside_storage — п. 20, абзац 2.

Используется та же Qwen3-VL-2B, новые веса не нужны. Основной проход не переписан.
Дополнительный запрос проверяет сразу 12 фактов; на выходе только состояния
и индексы кадров. При проверке наличных нельзя считать документ банкнотой.
Условия, исключения и ограничения перечислены в `docs/rule_coverage.md`.

## Айсане и Ерасылу

Для запуска общей сборки достаточно взять эту ветку в отдельную папку,
использовать рабочее CUDA-окружение, указать MODEL_PATH/API_KEY и запустить
команду из README. Свой backend с локальными изменениями не заменять вслепую.

Для переноса в уже собранную локальную backend-ветку:

1. Перенести актуальные `app/rules`, публичный метод
   `check_cash_rules_context` из `app/inference/model.py` и соответствующие тесты.
   Сохранить прочие актуальные исправления inference команды.
2. В обработчике после основного inference вызвать:

```python
from app.rules.context import enrich_service_context
from app.rules.decision import build_job_result

raw = engine.analyze_video(file_path).to_dict()
enriched = enrich_service_context(raw, file_path, engine.model, job_deadline)
response = build_job_result(job_id, enriched, extract_frame)
```

`job_deadline` — абсолютное значение `time.perf_counter()` начала задания + 300.
`extract_frame(seconds)` читает JPEG из текущего загруженного видео. Загрузка
движка остаётся один раз при старте worker. Файл удаляется после `build_job_result`.
Прежний отдельный вызов только ухода кассира убрать, чтобы не делать два прохода.

Ограничения: до четырёх контекстных окон, до 50 секунд суммарно, до 20 секунд
на запрос, по шесть кадров до 448 px. Это параметры первого рабочего подключения,
не измеренный оптимум. Новые запросы могут вернуть unclear или timeout.
Сводка `rule_context_summary` содержит только агрегаты и названия правил.
Публичный API сохраняет прежнюю схему без внутренних кандидатов.

## Проверка

`python -B -m evaluation.check_all`

Тест HTTP проверяет новый тип previous_cash_outside_storage до настоящего
JPEG из искусственного MOV. Отдельные тесты проходят все три положительных
пути, видимые опровержения, неопределённость, бюджет и невалидные ответы.
Модель в этих тестах подменена явно. Реальное качество Qwen здесь не заявляется.
На GPU нужно проверить реальные положительные и отрицательные примеры,
время, причины отказов и итоговые события. Кадры и описания остаются локально.
