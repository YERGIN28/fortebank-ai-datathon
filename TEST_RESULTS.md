# Результаты проверки

18 октября 2026. Windows, отдельное окружение Python 3.12.14.

## Автоматические тесты

`python -m pytest -q`: **151 passed, 73 subtests passed**.
Один warning библиотеки Starlette о будущем переходе с httpx на httpx2;
на результаты проверок не влияет. Текущий проверенный httpx зафиксирован.

Проверено:

- одинаковый 401 для отсутствующего, пустого и неверного ключа;
- отсутствующая серверная настройка ключа не даёт доступ;
- 400 для неподходящего расширения и пустого файла, 404 для неизвестного job;
- безопасные имена для Windows/POSIX путей, очистка частично записанного upload;
- битый MOV → failed; нормальный синтетический MOV → done;
- публичный API и UI-маршруты, декодирование JPEG, максимум 3 evidence frames;
- только два маршрута жюри в Swagger, без ключа в JavaScript;
- обработка двух заданий в одном потоке строго последовательно;
- timestamps внутри процесса без дополнительных полей в API;
- ошибка удаления файла не останавливает обработку следующего задания;
- отказ второго worker и освобождение блокировки после ошибки startup;
- однократные создание/загрузка подставного InferenceEngine в worker, два вызова
  analyze_video в том же потоке, refine=False и заданная конфигурация;
- partial/timeout/ошибки → failed, без no_violation;
- настоящий текущий Rule Engine для пустых, unknown и cash-наблюдений возвращает
  needs_review, который корректно становится failed;
- тесты автора Rule Engine и синтетические тесты актуального inference.

## Проверка запущенного сервера

Настоящий Uvicorn запускался на свободном локальном порту. `test_client.py`
выполнялся против него после каждого этапа изменений. В финале проверен
`start_backend.py --mode fake` и клиент, читающий ключ из `.env`.

На исходном `X-1.mov`: processing → done, Test violation, JPEG на отметке 10.0 с,
138080 символов чистого base64. Клиент: `API validation: PASSED`.
HTML UI возвращается сервером и содержит ожидаемые маршруты/формат изображения.
Интерактивный браузерный сценарий отдельно не автоматизировался.

`python -m pip check`: **No broken requirements found**.

## Границы проверки

Qwen на GPU не загружался: интеграция движка тестировалась с подставным engine,
а inference — синтетическими тестами автора. Реальные точность, скорость и VRAM
не измерялись. Это сборка для локальной демонстрации и дальнейшей интеграции,
не подтверждённая готовность production AI-сервиса.

Код `app/inference` совпадает с origin/ai, а `app/rules` и `evaluation` — с
origin/feat/rules-evaluation на зафиксированных в HANDOFF.md коммитах.
