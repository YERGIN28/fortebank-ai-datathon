# Проверка интегрированной сборки backend

Дата: 18 октября 2026. Финальную GPU-приёмку выполняет Айсана на RTX 4050.
Проверять точный SHA переданного backend, сверяя его через git rev-parse HEAD.

## Среда

Создан отдельный .venv (Python 3.12.14); исходный venv не менялся.
Проверенные импорты: torch 2.5.1+cu121, CUDA=True, NumPy 1.26.4,
OpenCV 4.11.0, FastAPI 0.143.3. pip check: No broken requirements found.
Web overlay requirements-web.txt с constraints-ai.txt проверен через dry-run:
изменения установленного AI-стека не требуются.

## Автоматические проверки

Команда: .\.venv\Scripts\python.exe -m pytest -q.
Для текущей интеграции AI 2026.10.18.3: 189 passed, 95 subtests passed.
Один предупреждающий сигнал Starlette о будущем переходе httpx→httpx2.

Проверены авторизация, безопасные загрузки, API/UI-маршруты, Swagger,
последовательная очередь, однократная загрузка движка, ошибки и очистка,
настоящие JPEG из тестового MOV, оба финальных вердикта правил, неизвестные
события, публичный check_service_context, тесты текущих ai и feat/rules-evaluation.
Дополнительно проверена цепочка текущего InferenceEngine с подставной моделью
через Rule Engine и UI-маршруты: observed → violation с настоящими JPEG,
refuted → no_violation, unclear → failed. Уход без наличных сохраняет условия
из AI; повторный контекстный вызов backend не происходит. После timeout очередь
продолжает работать, а журнал содержит только технические метрики.
Тесты подставной модели сами по себе не измеряют точность Qwen.

## Историческая GPU-проверка — только предыдущая сборка

На ноутбуке Erassul с RTX 3050 4 ГБ, AI 2026.10.18.1 (3092f9e), Qwen загрузился
на CUDA, сервер прошёл startup и отдавал HTML интерфейса.
HTTP-пробник автора AI на искусственном четырёхсекундном MOV прошёл успешно.
Результат: done / no_violation, violations=[], negative_control_passed=True. Время 225.619 с. HTML интерфейса, загрузка MOV и polling проверены. Интерактивный браузерный сценарий отдельно не проверялся. Это отрицательный контроль на фигурах, а не измерение точности на банковских видео.

На этом же RTX 3050 пользовательский запуск позднее вернул inference timeout.
Эти результаты не характеризуют RTX 4050 и не подтверждают текущую AI 2026.10.18.3.
Текущая сборка ещё не проходила финальный GPU/браузерный прогон на ноутбуке Айсаны.
